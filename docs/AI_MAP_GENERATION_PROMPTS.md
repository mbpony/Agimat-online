## HOW TO USE (Hunyuan3D 2.1)
- Web demo: https://3d.hunyuan.tencent.com or HF Space "tencent/Hunyuan3D-2.1"
- Best mode: **image-to-3D** — screenshot/crop a single object from our concept art
  (img/concept_barangay_liwanag.jpg, img/concept_grand_tiangge.jpg) and upload it.
- Text mode also works — use the prompts below, ONE OBJECT PER GENERATION.
- Export **GLB**, send to me via Dropbox like the Mangkukulam. I optimize + place them.
- Style suffix to append to EVERY text prompt:
  `, stylized low-poly game asset, hand-painted texture, Filipino fantasy style,
   single object on neutral background, no ground plane, game-ready`
